# timelock-ca

**Обратимые небулевы вычислительные субстраты.** Четыре лаборатории, в
которых информация никогда не уничтожается: топологический заряд-замок,
битовый решёточный газ с эмерджентной гравитацией, клеточный автомат с
бит-в-бит путешествием во времени и гамильтоновы нейросети, обучаемые с
O(1) памяти.

## Коротко

Современные вычисления — улица с односторонним движением: `x = f(x)`
уничтожает старый `x`, backprop хранит каждую активацию, float-округление
съедает биты. Этот проект — четыре контрразведчика против энтропии:

```console
$ timelock-ca margolus
{
  "entropy_conserved": true,
  "bit_exact_reversal": true,        ← 100 тактов вперёд, 100 назад,
  "endpoint_recovered": true,          решётка возвращается бит-в-бит
  "midpoint_match": true,              в исходное состояние
  "hamming_weight": 51
}

$ timelock-ca train
{
  "loss_first": 0.3313,
  "loss_last": 0.0848,
  "loss_decreased": true,
  "xor_accuracy_pct": 94.75          ← обучено с НУЛЁВЫМ хранением активаций
}
```

## Лаборатория 1 — Топологический заряд-замок (`topo`)

Эйлерова характеристика `χ = V − E + F` бинарной решётки, вычисленная
чисто целочисленными битовыми трюками, трактуется как **сохраняющийся
заряд**. Предлагаются случайные одиночные перевороты битов; каждый
переворот *отклоняется*, если меняет χ. Два кольца (χ = 0 каждое) под 200
шумовых предложений: меш сетка извивается, топология заперта.

```
до: два кольца               после 200 переворотов: всё те же два кольца
┌──────────┐                 ┌──────────┐
│ ┌──────┐ │   χ = 0         │ ┌──────┐ │   χ = 0
│ │ дыра │ │   ─────►        │ │ дыра │ │   ─────►  (рваные края,
│ └──────┘ │                 │ └──────┘ │    та же топология)
└──────────┘                 └──────────┘
```

Это «топологическая защита» — тот же принцип, что в квантовой памяти на
анионах, — вычисленный в чистом `uint8` numpy.

## Лаборатория 2 — Битовый решёточный газ и гравитация (`hpp`)

Газ HPP: 4 булевых канала (Вверх/Вниз/Влево/Вправо) стримятся, отражаются
от двух дисков-препятствий, лобово сталкиваются. Измеряем дисбаланс
давления на каждом диске: возникает суммарная **притягивающая сила** —
гравитация из чистых битов.

Гоча, исправленная в проде: наивный последовательный bounce-back
(`grid[opp] |= bounced`) молча *аннигилирует* частицы. Одновременный
парный обмен (`d ↔ противоположный` внутри препятствий, единый снапшот)
строго консервативен по массе — и тесты это доказывают.

## Лаборатория 3 — Бит-в-бит путешествие во времени (`margolus`)

Модель бильярдных шаров как клеточный автомат с разбиением Марголуса.
Каждый блок 2×2 преобразуется **перестановкой** из 16 возможных состояний
(LUT-таблицей):

```
0001 → 0010 → 0100 → 1000 → 0001     (одиночная частица орбитит: импульс сохранён)
1001 ↔ 0110                           (упругое столкновение двух частиц)
```

Поскольку каждое преобразование — биекция:
- вес Хэмминга (число частиц) *строго инвариантен* — `dH/dt = 0`;
- обращение времени — обратная LUT: без пересчёта, без чекпоинтов;
- **meet-in-the-middle**: T тактов вперёд из S₀ и T тактов назад из S(T);
  две временные волны сходятся в идентичных состояниях. Причинность здесь
  симметрична.

Наша BBM-таблица проверяется тестами на биективность всех 16 элементов, а
`forward∘backward == identity` бит-в-бит на 100 тактах.

## Лаборатория 4 — Симплектические сети с O(1) памятью при обучении (`train`)

Нейросеть как *гамильтонова система*: координаты `q` и импульсы `p`
эволюционируют под шагами leapfrog,

```
p_{i+1} = p_i + dt·tanh(q_i @ W_i + b_i)
q_{i+1} = q_i + dt·p_{i+1}
```

Каждый шаг в точности обратим, поэтому backprop не нуждается в сохранённых
активациях: **сопряжённая волна** (adjoint) идёт по времени назад,
пересчитывая каждый слой на лету. Пиковая память на активации:
**строго 0 байт** на любой глубине. Плюс Adam, полный батч, градиенты
выведены вручную.

| Эксперимент                          | Результат (дефолты этого репо)      |
|--------------------------------------|--------------------------------------|
| Разделение XOR, dim=4, depth=12      | 94.75% точности за 120 эпох          |
| sklearn digits (64-мерное фазовое пространство) | **97.1%** тест-точность за 60 эпох, полный батч |

Модель digits имеет линейную readout-голову на границе фазового
пространства; градиенты cross-entropy едут на сопряжённой волне назад
через 8 leapfrog-слоёв.

## Справка по CLI

```
timelock-ca topo      [--size 32] [--steps 200]
timelock-ca hpp       [--size 64] [--steps 300]
timelock-ca margolus  [--size 16] [--steps 100] [--mid-steps 40]
timelock-ca train     [--epochs 120] [--depth 12] [--n 400]
```

Все команды выдают JSON — гоните их в `jq` (почему бы и не Windows-версию)
и встраивайте в CI-гейты: `timelock-ca margolus` выходит с ненулевым кодом,
если путешествие во времени перестаёт быть бит-в-бит. Контроль качества
причинности.

## Почему обратимые вычисления важны

- **Принцип Ландауэра**: стирание бита стоит `kT·ln2` тепла. Бит-в-бит
  обратимый компьютер обходит этот фундаментальный пол.
- **Память adjoint**: обратимые сети позволяют обучать глубокие модели на
  крошечной VRAM (это тот же трюк, что RevNets/gradient checkpointing,
  доведённый до точного предела).
- **Физическое моделирование**: решёточные газы *и есть* Навье–Стокс в
  пределе, вычисленные без единого умножения с плавающей точкой.
- **Это красиво**: вселенная, где всегда можно отменить.
